# Remediation Prompt Standard

Every audit finding generates a copy-ready remediation prompt. Each prompt must include:

1. Website and affected page context.
2. The exact issue detected.
3. Plain-English explanation of why it matters.
4. Evidence observed by the audit agent when available.
5. A required outcome, not a vague suggestion.
6. Instructions to preserve working functionality.
7. Mobile-first, responsive and accessibility expectations.
8. Direction to avoid common vibe-coded design failure modes.
9. Regression testing requirements for links, forms, console errors and responsive breakpoints.
10. Acceptance criteria that allow the user to verify completion.

The prompt should be usable without requiring the user to translate technical audit language into implementation instructions.
