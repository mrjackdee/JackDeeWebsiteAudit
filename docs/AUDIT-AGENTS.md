# JackDee Website Audit Agent Model

The application coordinates specialist audit agents across every publicly discoverable page within the selected coverage tier.

## Agents

- Executive UI/UX Designer: hierarchy, layout rhythm, navigation, visual quality, consistency, interaction and premium-design signals.
- Web Architect: response performance, system-level quality and repository architecture when source is supplied.
- Senior Front-End Engineer: mobile readiness, responsive implementation and front-end structural issues.
- QA Analyst: route availability, broken links, placeholder controls and crawl coverage.
- Accessibility Specialist: language, headings, labels, alternative text and accessible control names.
- Security Analyst: passive security headers, HTTPS and mixed-content risks. No destructive penetration testing.
- SEO/AEO Strategist: page titles, descriptions, social metadata and structured data.
- Vibe-Code Reviewer: generic typography, excess spacing, repetitive rounded UI, gradients, oversized type and weak motion signals.

## Discovery

Routes are gathered from the starting URL, same-origin links, robots.txt sitemap declarations and XML sitemaps. The crawler follows newly discovered same-origin links until the selected safety tier is exhausted.

## Interaction boundary

The application inventories links, forms, buttons and page regions. It does not automatically perform destructive or side-effecting actions such as purchases, deletions, message sends, account changes or authenticated workflows without a future explicit authenticated-audit capability.

## Remediation prompts

Every finding is converted into a detailed prompt that includes the issue, affected page, evidence, required outcome, implementation constraints, acceptance criteria and regression-testing requirements. These prompts are designed to be pasted directly into a vibe-coding tool.
